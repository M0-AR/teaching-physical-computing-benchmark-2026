# Method — zero-to-hero reproducible benchmark (2026-2027)

## Protocol
1. **Ground truth first**: curriculum encoded verbatim from edX pages (in prompt) + arm.com/schools fetch (2026-10-03).
2. **One-search-at-a-time**: `websearch` → `free-search/search+research` → `openresearch/web+openalex/europepmc/news/hackernews/stackoverflow/bluesky` → `paper-search/arxiv/semantic/openalex/crossref/googlescholar/unified` → `duckduckgo` → `agent-reach` → `gitmcp` → `kaggle/everything+discussions+kernels` → `wiki` → `gsd/superpowers`. Backoff on 429, DuckDuckGo fallback, never parallel websearch.
3. **Live verification, keyless only**: OpenAlex, Crossref, Wikipedia REST, GitHub REST, StackExchange API, World Bank API. Every live call logs raw totals; offline → nulls saved, never fabricated.
4. **No hand-edits without verification**: all tables/figures are generated by `experiments/0*.py`; `make test && make run` is the gate.
5. **Docker**: `docker compose up --build` reproduces `results/` from scratch.
